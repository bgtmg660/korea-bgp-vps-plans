## BGP 到底买的是什么

BGP 在这里指的是多线路智能调度，机房同时接入电信、联通、移动的优质线路，按访问者的运营商自动选路。它解决的是"你的用户三网混杂，不知道谁是电信谁是移动"这个问题。

韩国机房常见的几种线路取向差别不小：

- **CN2**：电信的优质直连线路，电信用户体验最好，其他两家不一定沾光。
- **CMI**：移动的骨干直连，移动用户延迟表现最稳。
- **AS4837**：联通的优质线路，联通用户走这条最舒服。
- **多线 BGP**：上面几条混合调度，省去自己判断用户运营商。

所以第一个要提醒的点是：**韩国机房不等于韩国 BGP**。挂着"韩国 VPS"名头、实际走国际线路绕日本的机器不少，延迟直接破百。

这不是假设。VMISS 的韩国首尔产品线原来叫 KR.SEL.BGP，主打 CN2 加 BGP 三网直连，2025 年 5 月因上游机房线路调整，官方把产品改成了国际线路 KR.SEL.INTL，套餐配置和价格体系基本沿用。也就是说，网上那些写"韩国 BGP"的老测评，对照今天的官网可能已经不是一回事了。你搜到任何一篇讲韩国 BGP 的文章，先确认它讲的产品现在还在不在。
